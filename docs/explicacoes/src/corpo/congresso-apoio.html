3. Como os blocos votam

Cada bloco calcula uma pontuação de apoio para cada proposta. Ela soma vários fatores.

Apoio = afinidade ideológica + relação com o governo + interesse setorial + sua aprovação popular + ministérios + negociações + bônus (somente no Casual)

Afinidade ideológica

Se você propõe algo alinhado à visão do bloco, o apoio sobe. Se for o oposto, desce.

Relação com o governo

Relação +80 vota a favor de quase tudo. Relação −50 faz oposição sistemática.

Aprovação popular

Parlamentares querem se reeleger. Com aprovação alta, têm medo de votar contra. Com aprovação baixa, os blocos se afastam.

Ministérios

Pastas de peso dão apoio contínuo em todas as votações do bloco.

A decisão de voto Se o apoio do bloco passa de 0,20, a liderança orienta o SIM. A fração fiel do bloco (a coesão) vota sim. Os dissidentes votam com base em probabilidade, que cresce com o apoio.
