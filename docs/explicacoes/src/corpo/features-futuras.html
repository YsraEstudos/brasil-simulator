Há anotações salvas só neste navegador que ainda não estão no arquivo. Quer usá-las?

Navegue pelas pastas como no explorador de arquivos: clique numa pasta da árvore à esquerda, ou dê dois cliques num ícone de pasta para abri-la. Use ←, → e ↑ para voltar, avançar e subir. Arraste uma feature pela alça ⠿ para uma pasta (na árvore, no caminho ou num ícone) ou reordene dentro da pasta aberta. Arraste uma pasta para dentro de outra, ou para Features. Cada feature tem um post-it: clique nele para escrever. Tudo é guardado no arquivo docs/explicacoes/dados/features.js quando você clica em Salvar no arquivo (ou Ctrl+S).
